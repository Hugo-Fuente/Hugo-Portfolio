# HUGO.DEV_ // Portfólio Pessoal 💻

> **Arquitetura para sistemas que não podem parar.**

Este repositório contém o código-fonte do meu portfólio pessoal, construído do zero para refletir a minha identidade profissional e académica. O design foi inspirado em interfaces de terminais e painéis de cibersegurança, focando-se numa navegação imersiva e responsiva.

## 🎯 Sobre o Projeto

Sou o Hugo Gomes de la Fuente, estudante de Sistemas de Informação na UNICAMP, com foco em Cibersegurança, DevOps e Bancos de Dados. Este site serve como o meu cartão de visita digital, onde exponho as minhas competências, projetos (como visão computacional com drones e aplicações arquiteturais) e o meu modelo de operação.

## 🚀 Funcionalidades e Destaques Técnicos

- **Design "Cyber/Terminal":** Interface escura (Dark Mode nativo) com destaques em ciano e efeitos de desfoque de fundo (Glassmorphism/`backdrop-filter`).
- **Navegação Magnética (Scroll Snapping):** A página está dividida em blocos de ecrã inteiro (`100vh`), e o scroll "trava" suavemente em cada secção (`scroll-snap-type: y mandatory`), criando uma experiência de apresentação em formato de slides.
- **Totalmente Responsivo:** Utilização de Media Queries para garantir que a interface e as caixas biométricas flutuantes se adaptam perfeitamente a dispositivos móveis, tablets e monitores ultrawide.
- **Performance:** Sem frameworks pesadas. Apenas HTML5 e CSS3 puro, garantindo um carregamento ultrarrápido.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica.
- **CSS3:** Variáveis, Flexbox, CSS Scroll Snap, Animações e Máscaras de Imagem (`-webkit-mask-image`).
- **Figma:** Prototipação e extração de assets (ícones SVG).

## 📂 Como visualizar localmente

Como o projeto é construído em HTML e CSS estático, não requer processos de build complexos ou servidores.

1. Clone o repositório:
   ```bash
   git clone [https://github.com/Hugo-Fuente/SitePortifolioHTML.git](https://github.com/Hugo-Fuente/SitePortifolioHTML.git)
   ```
2. Navegue até à pasta do projeto:
   ```bash
   cd SitePortifolioHTML
   ```
3. Abra o ficheiro `index.html` no seu navegador web preferido.

*(Dica: Para a melhor experiência de desenvolvimento, pode usar a extensão "Live Server" no VS Code).*
