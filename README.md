## 🎨 Processo de Design & UX/UI (Figma)

Antes de escrever a primeira linha de código, o projeto passou por uma etapa detalhada de design de produto e prototipação no **Figma**. Isso reforça meu cuidado com a experiência do usuário (UX) e a interface (UI):
- **Identidade Visual (System Design):** Definição de uma paleta de cores focada em tons escuros e ciano neon, simulando o ambiente imersivo de operações de cibersegurança.
- **Tipografia e Hierarquia:** Uso estratégico de fontes monoespaçadas para exibir dados técnicos e de leitura rápida, combinadas com fontes robustas nos títulos para criar impacto editorial.
- **Prototipação Responsiva:** Criação de wireframes adaptáveis e testes mobile-first para garantir que as caixas biométricas flutuantes e a navegação magnética não quebrassem a usabilidade em telas menores.

## 🚀 Funcionalidades e Destaques Técnicos

- **Design "Cyber/Terminal":** Interface escura (Dark Mode nativo) com destaques em ciano e efeitos de desfoque de fundo (Glassmorphism/`backdrop-filter`)[cite: 30].
- **Navegação Magnética (Scroll Snapping):** A página é dividida em blocos de tela cheia (`100vh`), e o scroll "trava" suavemente em cada seção (`scroll-snap-type: y mandatory`), criando uma experiência de apresentação em formato de slides[cite: 30].
- **Totalmente Responsivo:** Utilização de Media Queries para garantir que a interface e as caixas biométricas flutuantes se adaptem perfeitamente a dispositivos móveis, tablets e monitores ultrawide[cite: 30].
- **Performance:** Sem frameworks pesados[cite: 30]. Apenas HTML5 e CSS3 puro, garantindo um carregamento ultrarrápido[cite: 30].

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica[cite: 30].
- **CSS3:** Variáveis, Flexbox, CSS Scroll Snap, Animações e Máscaras de Imagem (`-webkit-mask-image`)[cite: 30].
- **Figma:** Prototipação (UX/UI), testes de usabilidade e extração de assets (ícones SVG)[cite: 30].

## 📂 Como visualizar localmente

Como o projeto é construído em HTML e CSS estático, não requer processos de build complexos ou servidores[cite: 30].

1. Clone o repositório:
   ```bash
   git clone [https://github.com/Hugo-Fuente/SitePortifolioHTML.git](https://github.com/Hugo-Fuente/SitePortifolioHTML.git)
   ```
2. Navegue até a pasta do projeto:
   ```bash
   cd SitePortifolioHTML
   ```
3. Abra o arquivo `index.html` no seu navegador web preferido[cite: 30].

*(Dica: Para a melhor experiência de desenvolvimento, você pode usar a extensão "Live Server" no VS Code)[cite: 30].*
